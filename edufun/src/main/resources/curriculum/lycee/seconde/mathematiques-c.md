# Algèbre et analyse

## 2C-MA-01 | Calcul dans ℝ : intervalles et valeur absolue | 60 min
Objectif : Utiliser intervalles, valeur absolue et encadrements.
### Je retiens
> |x| = x si x ≥ 0 et |x| = −x si x < 0. |x − a| est la distance entre x et a.
= |x − 3| ≤ 2 ⇔ 1 ≤ x ≤ 5 ⇔ x ∈ [1 ; 5]
> Encadrer une somme : on ajoute membre à membre ; un produit (positifs) : on multiplie membre à membre.
### Je m'exerce
1. Résous |2x + 1| = 5.
2. Écris sous forme d'intervalle : |x + 2| < 3.
### Corrigé
1. 2x + 1 = 5 ou 2x + 1 = −5 → x = 2 ou x = −3.
2. −5 < x < 1 → x ∈ ]−5 ; 1[.

## 2C-MA-02 | Polynômes et factorisation | 60 min
Objectif : Factoriser un polynôme connaissant une racine.
### Je retiens
> Si a est racine de P (P(a) = 0), alors P(x) = (x − a)Q(x). On trouve Q par identification des coefficients ou division euclidienne.
### Je m'exerce
1. P(x) = x³ − 2x² − 5x + 6. Vérifie que 1 est racine et factorise P.
### Corrigé
1. P(1) = 1 − 2 − 5 + 6 = 0. P(x) = (x − 1)(x² − x − 6) = (x − 1)(x − 3)(x + 2).

## 2C-MA-03 | Équations et inéquations du second degré | 60 min
Objectif : Résoudre ax² + bx + c = 0 et étudier le signe du trinôme.
### Je retiens
= Δ = b² − 4ac
= Δ > 0 : deux racines x₁,₂ = (−b ± √Δ)/(2a) ; Δ = 0 : une racine double −b/(2a) ; Δ < 0 : pas de racine réelle
> Le trinôme est du signe de a à l'extérieur des racines et du signe contraire entre les racines.
### Je m'exerce
1. Résous 2x² − 3x − 2 = 0.
2. Résous x² − 4x + 3 < 0.
### Corrigé
1. Δ = 9 + 16 = 25 ; x = (3 ± 5)/4 → x = 2 ou x = −1/2.
2. Racines 1 et 3, a > 0 : x ∈ ]1 ; 3[.

## 2C-MA-04 | Systèmes d'équations linéaires | 55 min
Objectif : Résoudre un système de deux ou trois équations par combinaison ou par la méthode de Cramer.
### Je retiens
> Pour ax + by = c et a'x + b'y = c' : déterminant D = ab' − a'b. Si D ≠ 0, solution unique : x = (cb' − c'b)/D ; y = (ac' − a'c)/D.
### Je m'exerce
1. Résous : 3x + 2y = 7 et x − y = −1.
### Corrigé
1. D = −3 − 2 = −5 ; x = (−7 + 2)/(−5) = 1 ; y = (−3 − 7)/(−5) = 2.

## 2C-MA-05 | Généralités sur les fonctions | 60 min
Objectif : Déterminer l'ensemble de définition, étudier la parité et le sens de variation.
### Je retiens
> f est paire si f(−x) = f(x) (courbe symétrique par rapport à l'axe des ordonnées) ; impaire si f(−x) = −f(x) (symétrique par rapport à l'origine). f est croissante sur I si a < b ⇒ f(a) ≤ f(b).
### Je m'exerce
1. Ensemble de définition de f(x) = √(x − 2) / (x − 5).
2. f(x) = x³ − x est-elle paire ou impaire ?
### Corrigé
1. x ≥ 2 et x ≠ 5 : D = [2 ; 5[ ∪ ]5 ; +∞[.
2. f(−x) = −x³ + x = −f(x) : impaire.

## 2C-MA-06 | Fonctions de référence | 55 min
Objectif : Connaître les variations et les courbes de x², 1/x, √x, |x|.
### Je retiens
- x ↦ x² : décroissante sur ]−∞ ; 0], croissante sur [0 ; +∞[ (parabole).
- x ↦ 1/x : décroissante sur ]−∞ ; 0[ et sur ]0 ; +∞[ (hyperbole).
- x ↦ √x : croissante sur [0 ; +∞[.
### Je m'exerce
1. Compare sans calculer : (−3,1)² et (−2,9)².
### Corrigé
1. Sur ]−∞ ; 0], x² est décroissante et −3,1 < −2,9, donc (−3,1)² > (−2,9)².

# Géométrie

## 2C-MA-07 | Calcul vectoriel | 60 min
Objectif : Utiliser la relation de Chasles, la colinéarité et le barycentre de deux points.
### Je retiens
= Chasles : AB + BC = AC (vecteurs)
> Deux vecteurs u(x ; y) et v(x' ; y') sont colinéaires si xy' − x'y = 0. Le barycentre G de (A ; a) et (B ; b), a + b ≠ 0, vérifie a·GA + b·GB = 0.
### Je m'exerce
1. u(2 ; −3), v(−4 ; 6) sont-ils colinéaires ?
### Corrigé
1. 2 × 6 − (−4)(−3) = 12 − 12 = 0 : oui.

## 2C-MA-08 | Droites du plan : équations | 60 min
Objectif : Déterminer une équation cartésienne et réduite de droite.
### Je retiens
> Équation réduite : y = mx + p (m : coefficient directeur). Équation cartésienne : ax + by + c = 0, vecteur directeur u(−b ; a). Deux droites sont parallèles si elles ont le même coefficient directeur.
### Je m'exerce
1. Équation de la droite passant par A(1 ; 2) et B(3 ; 8).
### Corrigé
1. m = (8 − 2)/(3 − 1) = 3 ; p = 2 − 3 = −1 ; y = 3x − 1.

## 2C-MA-10 | Statistiques : séries à caractère continu | 55 min
Objectif : Calculer moyenne, variance et écart-type d'une série groupée en classes.
### Je retiens
> On utilise le centre des classes. Variance V = (Σ nᵢxᵢ²)/N − x̄² ; écart-type σ = √V. Plus σ est grand, plus la série est dispersée.
### Je m'exerce
1. Série : 2, 4, 6, 8. Calcule la moyenne et l'écart-type.
### Corrigé
1. x̄ = 5 ; V = (4 + 16 + 36 + 64)/4 − 25 = 30 − 25 = 5 ; σ = √5 ≈ 2,24.
